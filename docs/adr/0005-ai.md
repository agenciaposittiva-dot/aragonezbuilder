# ADR 0005 — Camada de IA com provedores intercambiáveis

**Status:** aceita · 18/10/2026

## Decisão
- Interface `AiProvider` (`src/server/ai/types.ts`) com implementações **Anthropic**
  (SDK oficial, padrão `claude-opus-5-5`, streaming, `fallbacks: "default"` para recusas
  dos filtros de segurança), **OpenAI** (API oficial, modelo definido pela organização) e
  **Demonstração** (local, sem enviar dados, usada quando não há chave).
- Os módulos só conhecem a interface; trocar de provedor é uma configuração.
- **Privacidade:** dados de clientes (tom de voz, público, identidade, serviços, projetos)
  só entram no prompt se a organização autorizar (`allowClientContext`). Cada geração
  usa no máximo um cliente — nunca mistura marcas.
- **Controle:** limites mensais de tokens por organização e diários por pessoa; registro
  de provedor, modelo, usuário, cliente, operação, tokens, custo estimado, latência,
  resultado e erro em `ai_usage`.
- **Fluxos assistidos:** a IA sugere (ex.: tarefas de um projeto); nada é criado sem
  revisão e confirmação explícita do usuário. O modelo não executa código nem consulta
  o banco.
- Chaves de API por organização ficam criptografadas (AES-256-GCM, `ENCRYPTION_KEY`).
